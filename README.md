## 🚀 Featured Projects

### 🔹 NextHire AI — AI-Powered Job Portal

A full-stack job portal that scores a candidate's resume against a job description using the **Gemini API**, so applicants can see how an ATS would read their resume before they apply.

**Tech:** React • Node.js • Express.js • MongoDB • Tailwind CSS • Gemini API

**What it does**
- ATS-style resume scoring against any job description, powered by Gemini
- Resume parsing and structured feedback on gaps and keyword matches
- Role-based flows for job seekers and recruiters
- REST API backend on Node.js + Express with MongoDB persistence
- Responsive React interface built with Tailwind CSS

🔗 **Repository:** `YOUR_REPOSITORY_LINK`

### 🔹 MedLedger — Blockchain Medical Record Verification

A prototype that anchors medical records on-chain so their integrity can be verified without trusting a central database.

**My Role:** Project Manager & Frontend Developer

**Tech:** React • JavaScript • Solidity • Remix IDE • Ethereum Sepolia • Ethers.js

**What it does**
- Solidity smart contract deployed to the Ethereum Sepolia testnet
- React frontend connected to the contract via Ethers.js for read/write calls
- Record-hash verification flow that flags any tampering
- Led planning and task breakdown for the team alongside frontend development

🔗 **Repository:** `YOUR_REPOSITORY_LINK`
